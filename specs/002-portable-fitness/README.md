# Portable fitness instruction set

## Decision

Generalize fitness planning into one host-neutral source with seven standalone draft distribution copies and target-specific application notes. The Claude-area instructions.md owns edits; a parity regression test prevents drift. This preserves the existing platform layout and requires no runtime includes or installer.

## Safety and privacy

Use blank context rather than a personal profile. The source contains no individual history, metrics, locations, schedule, medications or predicted physique outcome. Support sustainable adult fitness with symptom escalation, medical boundaries, uncertainty, consent and optional tracking. No universal numeric target or purported medical optimization is inherited.

## Verification and release

Run repository validation and all unit tests, including snapshot parity and metadata checks. Review the complete outbound diff for private data. Host tests remain explicitly not run; no clinical efficacy validation is claimed. Keep all adaptations draft and unlisted. Gemini and Perplexity entries are candidate adaptations only and do not change the repository's overall support claim. Publish only after recorded appropriate host checks and review; merging requires separate authorization.
