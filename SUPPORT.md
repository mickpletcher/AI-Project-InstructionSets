# Support

Use [GitHub issues](https://github.com/mickpletcher/AI-Project-InstructionSets/issues/new/choose) for questions, bugs, and proposals. Include the instruction-set path, commit, host/version, sanitized prompt, expected result, and observed result. No response-time or host compatibility guarantee is offered. Read [installation guidance](docs/installation.md) first. Security concerns belong in [SECURITY.md](SECURITY.md).
